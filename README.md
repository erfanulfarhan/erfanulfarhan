## Featured

### [Lens](https://github.com/erfanulfarhan/lens) &nbsp;<sup>`electron` `typescript` `swift` `local llm`</sup>

A desktop AI assistant that reads your screen and follows your calls, answering from documents you give it. The model runs on **your own machine**, so it is free to use and nothing leaves your computer. Retrieval over your own files, on-device transcription, and a model recommendation based on your hardware.

**[Download for macOS or Windows →](https://github.com/erfanulfarhan/lens/releases)**

### [exam-toolkit](https://github.com/erfanulfarhan/exam-toolkit) &nbsp;<sup>`typescript` `react`</sup>

Revision tools for Edexcel International A Level and IGCSE. A UMS grade calculator built from every published boundary, past papers beside mark schemes that stay locked until you attempt the question, plus a mock timer and study planner.

### [sitesage](https://sitesage-erfanul.vercel.app) &nbsp;<sup>`javascript` `groq` `postgres`</sup>

An embeddable AI chat widget for any site. Create a bot, train it on text or URLs, drop in one script tag. Multi-tenant, so a single deployment serves every customer.

### [ask-my-docs](https://ask-my-docs-erfanul.vercel.app) &nbsp;<sup>`javascript` `pgvector`</sup>

Retrieval over your own PDFs and notes, answering **with citations** back to the exact source passage. Embeddings run in the browser; Supabase pgvector does the search.

### [store-it](https://github.com/erfanulfarhan/store-it) &nbsp;<sup>`typescript` `next` `appwrite`</sup>

File storage with passwordless email sign-in. Download links are minted per request and expire, so a shared URL stops working instead of living forever.

### [cineplex-bot](https://github.com/erfanulfarhan/cineplex-bot) &nbsp;<sup>`python` `playwright`</sup>

A Telegram bot for Star Cineplex: live seat availability, rendered seat maps, and standing orders that book the moment tickets go on sale.
